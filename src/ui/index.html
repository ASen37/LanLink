安全模型

  • 每台设备生成独立的 Ed25519 身份密钥，设备 ID 由公钥哈希派生。
  • 连接时使用临时 X25519 密钥协商，会话密钥经 HKDF-SHA256 派生。
  • 所有控制消息与文件分块均使用 AES-256-GCM 加密与认证。
  • 配对时双方显示相同的 6 位校验码，可防止中间人攻击。
  • 分块逐块 SHA-256 校验，失败自动重传。
  • 访客模式是 HTTP 明文，仅建议在可信局域网内开启。
